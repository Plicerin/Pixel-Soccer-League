# Bug Tracker

- [ ] **WR Naming Issue**: Dolphins Wide Receivers are all being named "Tyreek Hill" regardless of the roster list.
- [ ] **Kit Color Toggle Not Working**: Home/Away kit toggle buttons in the options panel call `setTeamColors` with correct hex values, but player voxels on the field don't visually update. Root cause: voxel meshes may not reference the shared `M.teamAShirt`/`M.teamBShirt` material instances. Even after reassigning materials in `setTeamColors`, the change doesn't render. Needs deeper investigation into the Three.js material/render pipeline.
- [x] **Gamepad Pause Won't Unpause**: Start button pauses the game but pressing it again does not unpause. **Fixed**: Gamepad Start button check was inside the main loop which is skipped during pause. Added gpJustPressed(9) check before the early return.
- [x] **P1 Free Kicks Taken Automatically**: When player one's team earns a free kick, it is executed by CPU AI instead of letting the human player take it. **Fixed**: Added `humanWaiting` state — after the whistle, the taker holds the ball and waits for the player to pass/shoot. CPU free kicks still auto-execute.
- [x] **CPU Goalie Throws Ball Out of Bounds**: CPU goalkeeper distribution frequently sends the ball directly out of play. **Fixed**: Added sideline protection to keeper throws (was missing), widened kick sideline margin from 2.5 to 4 yards, added 1.3× overshoot prediction.
- [x] **CPU Won't Restart After Goal**: After a goal is scored, CPU-vs-CPU or the CPU side fails to restart the game. **Fixed**: Added auto-execute of kickoff touch for CPU teams in 1P/2P mode. Also fixed Space/A button to work when isLive is already true during kickoff-ready state.
